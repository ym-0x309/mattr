# MATTR

> `MATTR`는 `Mesh Attribute & Topology Transfer Representation`의 약자로,\
> Blender에서 제작한 메쉬를 attribute 데이터가 보존된 상태로 자체 엔진이나 툴로 가져오기 위한 포맷입니다.\
> 자세한 내용은 [명세](/SPECIFICATION.md)를 참고하십시오.

## Blender MATTR Exporter

Blender에서 제작한 메쉬를 MATTR 포맷으로 내보내는 익스텐션입니다.

자세한 내용은 [해당 파일](/blender_mattr_exporter/docs/overview.md)를 참고하십시오.
